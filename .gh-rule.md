# Repository Git policy

## Branches and checkout

- Mainline branch: `dev`.
- Use the canonical checkout
  `/home/kike/ws/scene-reconstruction-ws/colmap-reconstruction-ws/colmap-reconstruction-ws`.
- Use one branch per agent-workspace task, named `task/TASK-XXXX-short-title`.
- Do not use additional worktrees or run task work in parallel in this repository.

## Commits and validation

- Stage only reviewed, task-scoped paths; never use blanket staging.
- Before each commit, run `git diff --check` and the task's applicable
  validation commands.
- Record the task branch, commit, validation, and integration evidence in the
  task record after Git-state changes.

## Integration

- Do not commit implementation work directly to `dev`.
- Do not push, open a pull request, merge, or delete a task branch without
  explicit user approval.
- Before an approved merge, review the task-branch-to-`dev` commit range,
  validation evidence, unrelated changes, conflicts, ordering, and residual
  risk.
